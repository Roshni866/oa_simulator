# Roadmap

## Milestone 0 — Foundation and project rules

Acceptance criteria: repository and prerequisites inspected; shared documentation exists and agrees; a minimal FastAPI health endpoint has a passing test; Git status is understandable; the student reviews the checkpoint before Milestone 1.

## Milestone 1 — Frontend foundation and challenge dashboard

Acceptance criteria: Vite app runs, routing works, a typed challenge list renders, and frontend tests cover the main dashboard behavior.

## Milestone 2 — Assessment workspace and editor

Acceptance criteria: a challenge opens in a workspace, starter code is visible in Monaco, and editor state is handled predictably.

## Milestone 3 — FastAPI integration

Acceptance criteria: frontend reads challenge data from the backend, API errors are represented in the UI, and endpoint tests exist.

## Milestone 4 — Predefined challenges and controlled evaluation

Acceptance criteria: trusted challenge workflows run with bounded resources and return reproducible results; arbitrary submitted code is not run in-process.

## Milestone 5 — PostgreSQL and submission history

Acceptance criteria: migrations, models, persistence, and history views work in local development.

## Milestone 6 — Progressive AI hints and feedback

Acceptance criteria: backend-only provider integration is optional, failures are handled, and hints do not replace transparent test feedback.

## Milestone 7 — Tracking, resilience, and polish

Acceptance criteria: progress metrics, loading/error/empty states, accessibility checks, and performance basics are covered.

## Milestone 8 — Final verification and delivery

Acceptance criteria: frontend/backend tests, documentation, deployment notes, and interview preparation are complete.
